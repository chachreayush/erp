1. Purpose & Scope
DOC-28 is the control layer that proves whether recorded cash/bank transactions agree with external bank statements and physical cash. It does not replace DOC-24 transaction entry, DOC-07 settlement, DOC-08 posting, or DOC-09 ledger/open-item architecture.

2. Reconciliation Architecture
3. Statement Ingestion & Normalization
• Support CSV/Excel and structured bank files; provider-specific columns are mapped through a versioned import profile.
• Capture statement account, statement period, opening balance, closing balance, transaction date/value date, debit/credit, amount, bank reference, cheque/instrument reference and narration.
• Normalize signs, currency, date formats and reference strings before matching; retain the original imported row for audit.
• Hash each imported raw row using a stable source fingerprint to prevent duplicate imports.

6. Cash Control
• Maintain cashbook closing, physical cash count, denomination breakdown, counted amount, variance and approver.
• Allow multiple cash locations/registers per branch; each register has custodian, opening float, permitted limits and close status.
• Positive/negative variance requires reason code and, above configured threshold, approval.
• Cash transfers between registers are separate controlled movements, not journal-only edits.

10. Audit, Security & Approvals
• Never delete imported statement evidence; corrections are reversals/amendments.
• Log import file hash, user, machine/session, timestamp, source period and mapping profile.
• Role permissions distinguish view, auto-match approval, manual match, adjustment creation, cash close and period unlock.
• Reconciliation lock is period-aware and cannot silently alter posted accounting.
11. Reports, Integrations & Acceptance Criteria
• Reports: bank reconciliation statement, outstanding bank items, cheque aging, unknown receipts/payments, bank charges, cash variance, daily cash position, unreconciled aging.
• Integrations: DOC-24 transactions; DOC-07 allocation; DOC-08 posting; DOC-09 GL/open items; DOC-25 journals; DOC-26 expenses.
• Acceptance: duplicate imports blocked; exact matches auto-link; manual matches auditable; period balances reconcile; cash variance cannot be hidden; reversal preserves original history.
