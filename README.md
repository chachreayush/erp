# ERP Software

A multi-tenant, offline-first ERP system built for the Account Master (AM) / Client Module (CM) model.

## Tech Stack
- **Desktop App:** Tauri 2.0 + React + TypeScript
- **Backend API:** Python + FastAPI
- **Server Database:** PostgreSQL
- **Remote Offline Cache:** SQLite
- **Cloud Bridge:** Supabase

## Project Structure
```
erp/
├── backend/        ← Python FastAPI server
├── src/            ← React + TypeScript frontend
├── src-tauri/      ← Tauri Rust desktop shell
├── database/       ← SQL schemas and migrations
└── installers/     ← Installer build scripts
```
